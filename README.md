# Python Assignment

This repository contains Python assignments developed with an emphasis on clean code, maintainability, testing, and software engineering best practices.

## Requirements

The assignments focus on:

- PEP 8 coding standards
- Appropriate software design principles
- Python logging standards
- Exception handling
- Configuration management
- Unit testing and Test-Driven Development (TDD)

## Programs

1. Python Unit Testing and Test-Driven Development
2. MySQL Database Processing Using Generators
3. Person and Gender
4. Removing Duplicates While Preserving Order
5. Using `map()` and `lambda` to Calculate Squares
6. Removing HTML Tags from Web Content

## Technologies

- Python
- MySQL
- pytest
- unittest and unittest.mock
- boto3 and moto
- Git and GitHub

Each assignment includes its implementation, relevant tests, and instructions for execution in its respective folder.
